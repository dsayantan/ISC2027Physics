Relations and Functions

Types of relations; one-one, onto, into; composite functions; inverse of a function; conditions of invertibility.

Type 1 · Testing a relation for reflexive / symmetric / transitive

How to attack itCheck the three properties one at a time, in that order. For each, either give a general proof or a single explicit counterexample. Transitivity is where marks are lost — hunt for a counterexample first, before trying to prove it.
P14 marksHeritage First Term 2024–25, Q8
Test whether the relation R on ℤ defined by R = {(a, b) : |a − b| ≤ 5} is reflexive, symmetric and transitive.
  1. Reflexive. For any a ∈ ℤ, |a − a| = 0 ≤ 5, so (a, a) ∈ R. R is reflexive.
  2. Symmetric. If (a, b) ∈ R then |a − b| ≤ 5. Since |b − a| = |a − b| ≤ 5, (b, a) ∈ R. R is symmetric.
  3. Transitive. Take a = 1, b = 5, c = 10. Then |1 − 5| = 4 ≤ 5 and |5 − 10| = 5 ≤ 5, so (1, 5) ∈ R and (5, 10) ∈ R. But |1 − 10| = 9 > 5, so (1, 10) ∉ R. R is not transitive.

Answer Reflexive and symmetric, but not transitive.

Trap A counterexample must satisfy both hypotheses (a,b) and (b,c) and fail the conclusion. Numbers that are 5 apart each time, adding to more than 5, are the ones to reach for.

P21 markNCERT Exemplar Ch 1, Q31
A relation R on the set {1, 2, 3} is defined by R = {(1, 2)}. Classify R.
  1. Reflexive? (1,1) ∉ R, so not reflexive.
  2. Symmetric? (1,2) ∈ R but (2,1) ∉ R, so not symmetric.
  3. Transitive? Transitivity needs a pair (a,b), (b,c) in R. The only element is (1,2), and (2, c) ∉ R for every c, so the hypothesis is never satisfied. A statement with a false hypothesis is vacuously true, so R is transitive.

Answer R is transitive only.

Note A single-element relation {(a, b)} with a ≠ b is always transitive and never reflexive or symmetric. This vacuously true reasoning is the whole point of the question.

P34 marksStandard ISC type
Show that the relation R on ℤ defined by R = {(a, b) : 5 divides (a − b)} is an equivalence relation. Write its equivalence classes.
  1. Reflexive. 5 | (a − a) = 0 for every a, so (a, a) ∈ R.
  2. Symmetric. If 5 | (a − b), write a − b = 5k. Then b − a = −5k, which is divisible by 5, so (b, a) ∈ R.
  3. Transitive. If a − b = 5k and b − c = 5m then a − c = 5(k + m), divisible by 5, so (a, c) ∈ R.
  4. Hence R is an equivalence relation. Two integers are related exactly when they leave the same remainder on division by 5, so the classes are the five remainder classes.

Answer [0], [1], [2], [3], [4] — five equivalence classes, [r] = {5n + r : n ∈ ℤ}.

Type 2 · Deciding one-one / onto for a given domain and codomain

How to attack itInjectivity: start from f(x₁) = f(x₂) and force x₁ = x₂, or use strict monotonicity via f′. Surjectivity: compute the range and compare it with the declared codomain — never with ℝ by habit.
P41 markHeritage First Term 2024–25, Q1(vi)
Let A = {x : −1 ≤ x ≤ 1} and let f : A → A be defined by f(x) = x|x|. Then f is: (a) a bijection  (b) injective but not surjective  (c) surjective but not injective  (d) neither.
Write f without the modulus:
f(x) = {x20 ≤ x ≤ 1−x2−1 ≤ x < 0
  1. On [0, 1], f(x) = x2 increases from 0 to 1. On [−1, 0), f(x) = −x2 increases from −1 to 0. So f is strictly increasing across the whole of A.
  2. Strictly increasing ⇒ injective.
  3. The values run over [−1, 1] = A, with f(−1) = −1 and f(1) = 1 attained, so f is onto A.

Answer (a) a bijection.

Note Note how the codomain was declared to be A, not ℝ. Had the codomain been ℝ the same rule would not be surjective.

P51 markHeritage First Term 2024–25, Q1(ii)
Let f : [2, ∞) → ℝ be defined by f(x) = x2 − 4x + 5. Find the range of f.
  1. Complete the square: f(x) = (x − 2)2 + 1.
  2. For x ≥ 2, (x − 2)2 ≥ 0 and increases without bound.
  3. So f(x) ≥ 1, with the value 1 attained at x = 2.

Answer Range = [1, ∞).

Trap The vertex of the parabola is at x = 2, which is the endpoint of the domain. If the domain had been [3, ∞) the answer would be [2, ∞) instead — always check whether the vertex lies inside the given domain.

P61 markHeritage First Term 2024–25, Q1(xii)
The function f : ℝ → ℝ, f(x) = x2 − 4 is many-one. Give a reason.

Answer f(2) = 0 = f(−2) with 2 ≠ −2, so two distinct inputs share an output.

Note One explicit pair is a complete answer for a 1-mark ‘give a reason’. There is no need to discuss the whole function.

P72 marksProject link
Show that f : ℝ → ℝ, f(x) = ex is injective but not surjective, and state the change that makes it a bijection.
  1. If ex₁ = ex₂, taking natural logarithms gives x₁ = x₂, so f is injective.
  2. ex > 0 for every real x, so y = −2 has no pre-image. Hence f is not onto ℝ and Ran(f) = (0, ∞).
  3. Redeclaring the codomain as (0, ∞) makes f a bijection, with inverse f−1(x) = ln x.

Note This is exactly your project's central point: only the codomain changed — the rule and the domain did not.

Type 3 · Proving invertibility and finding the inverse

How to attack itShow one-one, show onto (usually by solving y = f(x) for x), then read off f⁻¹ from that solution. State the domain of the inverse: it is the codomain of f.
P84 marksNCERT Ch 1, standard
Let f : → ∞ [−6, ∞) be given by f(x) = 9x2 + 6x − 5, where the domain is [−13, ∞). Show that f is invertible and find f−1.
  1. Complete the square: f(x) = (3x + 1)2 − 6.
  2. On x ≥ −13 we have 3x + 1 ≥ 0, so (3x + 1)2 is strictly increasing; hence f is injective.
  3. Set y = (3x + 1)2 − 6, so (3x + 1)2 = y + 6. Since 3x + 1 ≥ 0 we take the non-negative root: 3x + 1 = √y + 6, giving x = √y+6 − 13.
  4. For every y ≥ −6 this x lies in the domain, so f is onto [−6, ∞) and therefore invertible.

Answer f−1(y) = √y+6 − 13, y ≥ −6.

Trap Both signs of the square root solve the quadratic; the domain x ≥ −13 is what selects the + sign. Dropping that is the commonest error here.

P94 marksStandard ISC type
Let f : ℝ − {23} → ℝ − {23} be defined by f(x) = 4x + 36x − 4. Show that f is a bijection and find f−1.
  1. One-one. f(x₁) = f(x₂) gives (4x₁ + 3)(6x₂ − 4) = (4x₂ + 3)(6x₁ − 4). Expanding, 24x₁x₂ − 16x₁ + 18x₂ − 12 = 24x₁x₂ − 16x₂ + 18x₁ − 12, so 34x₂ = 34x₁, i.e. x₁ = x₂.
  2. Onto. Put y = 4x + 36x − 4 and solve for x: y(6x − 4) = 4x + 3, so x(6y − 4) = 4y + 3, giving x = 4y + 36y − 4, which is defined for every y ≠ 23.
  3. Hence f is a bijection and the formula for x is the inverse.

Answer f−1(y) = 4y + 36y − 4 — f is its own inverse (an involution).

Type 4 · Composite functions and counting functions

How to attack itFor gof always apply f first. For counting, one-one maps need |A| ≤ |B| and onto maps need |A| ≥ |B|.
P102 marksStandard ISC type
If f(x) = x2 + 1 and g(x) = 2x − 3, find (gof)(x) and (fog)(x). Are they equal?
  1. (gof)(x) = g(f(x)) = g(x2 + 1) = 2(x2 + 1) − 3 = 2x2 − 1.
  2. (fog)(x) = f(g(x)) = f(2x − 3) = (2x − 3)2 + 1 = 4x2 − 12x + 10.

Answer gof ≠ fog, so composition of functions is not commutative.

P111 markExemplar-style objective
How many one-one functions are there from a set with 3 elements to a set with 4 elements? How many onto functions are there in the other direction?
  1. One-one from a 3-set to a 4-set: choose an image for each of the 3 elements without repetition — 4 × 3 × 2 = 24.
  2. Onto from a 4-set to a 3-set: total maps 34 = 81, minus those missing at least one image. By inclusion–exclusion, 34 − 3×24 + 3×14 = 81 − 48 + 3 = 36.

Answer 24 one-one functions; 36 onto functions.

P122 marksStandard ISC type
Let f : ℕ → ℕ be defined by f(n) = n + 1 if n is odd and f(n) = n − 1 if n is even. Show that f is a bijection.
  1. f pairs 1 → 2, 2 → 1, 3 → 4, 4 → 3, and so on: f swaps each odd number with the even number above it.
  2. Hence f(f(n)) = n for every n, so f is its own inverse.
  3. A function with a two-sided inverse is a bijection.

Answer f is a bijection, and f−1 = f.

Note Exhibiting an inverse is usually faster than checking one-one and onto separately.

Inverse Trigonometric Functions

Definition, domain, range, principal value branch; elementary properties; formulae for 2sin⁻¹x, 2tan⁻¹x etc.

Type 1 · Principal values, including arguments outside the branch

How to attack itsin⁻¹(sin x) = x only for x in [−π/2, π/2]. Otherwise reduce the angle into the principal branch first, using sin(π − x) = sin x, cos(2π − x) = cos x, tan(x − π) = tan x.
P132 marksStandard ISC type
Evaluate: sin−1(sin 3π4), cos−1(cos 7π6) and tan−1(tan 5π6).
  1. 3π4 is not in [−π2, π2], the range of sin−1. But sin 3π4 = sin(π − 3π4) = sin π4, and π4 is in the branch. So sin−1(sin 3π4) = π4.
  2. 7π6 is not in [0, π], the range of cos−1. Use cos 7π6 = cos(2π − 7π6) = cos 5π6, and 5π6 ∈ [0, π].
  3. 5π6 is not in (−π2, π2), the range of tan−1. Use tan 5π6 = tan(5π6 − π) = tan(−π6) = −tan π6.

Answer π4,   5π6,   −π6.

Trap Writing sin−1(sin 3π4) = 3π4 is the single most common error in this chapter. Always check the branch first.

Type 2 · Using sin⁻¹x + cos⁻¹x = π/2

How to attack itWhenever both sin⁻¹ and cos⁻¹ of the same argument appear, replace one using sin⁻¹x + cos⁻¹x = π/2. Almost every ‘find the range’ question here is that one line.
P141 markHeritage First Term 2024–25, Q1(iii)
If a ≤ cos−1x + 2 sin−1x ≤ b, then find a and b.
  1. Split off one sin−1: cos−1x + 2 sin−1x = (cos−1x + sin−1x) + sin−1x.
  2. The bracket is π/2, a constant, so the expression equals π/2 + sin−1x.
  3. sin−1x ranges over [−π2, π2], so the expression ranges over [π/2 − π/2, π/2 + π/2] = [0, π].

Answer a = 0, b = π.

P152 marksHeritage First Term 2024–25, Q3
Find x such that cos(sin−12√5 + cos−1x) = 0.
  1. cos θ = 0 with θ a sum of principal values forces θ = π2.
  2. So sin−12√5 + cos−1x = π2.
  3. Hence cos−1x = π2 − sin−12√5 = cos−12√5, using π/2 − sin−1t = cos−1t.
  4. cos−1 is one-one on [−1, 1], so x = 2√5.

Answer x = 2√5 = 2√55.

Type 3 · Reducing an expression to a principal value

How to attack itTurn the argument into a single sine or cosine of a compound angle, then decide which reduction formula applies from the interval given for x. The interval is never decoration.
P164 marksHeritage First Term 2024–25, Q7
Find the value of cos−1[sin x + cos x√2], where 5π4 < x < 9π4.
  1. sin x + cos x√2 = cos x cos π4 + sin x sin π4 = cos(x − π4).
  2. So the expression is cos−1(cos(x − π4)).
  3. Given 5π4 < x < 9π4, subtracting π4 gives π < x − π4 < 2π.
  4. For θ ∈ (π, 2π), cos−1(cos θ) = 2π − θ.
  5. Hence the value is 2π − (x − π4) = 9π4 − x.

Answer 9π4 − x.

Trap The whole question turns on locating x − π/4 in (π, 2π). Skipping that step and writing x − π/4 loses every mark.

P172 marksStandard ISC type
Write tan−1√1 − cos x1 + cos x in simplest form, for 0 < x < π.
  1. Use 1 − cos x = 2sin2(x/2) and 1 + cos x = 2cos2(x/2).
  2. The radicand becomes tan2(x/2), so the radical is |tan(x/2)|.
  3. For 0 < x < π we have 0 < x/2 < π/2, where tan(x/2) > 0.
  4. So the expression is tan−1(tan(x/2)) = x/2, since x/2 lies in the principal branch.

Answer x/2.

Type 4 · Solving inverse-trigonometric equations

How to attack itMove one term across, take sine (or tangent) of both sides, then solve the algebraic equation. Always substitute the roots back — squaring introduces extraneous ones.
P184 marksHeritage First Term 2024–25, Q7 (OR)
Solve: sin−14x5 + sin−13x5 = sin−1x.
  1. Rewrite as sin−13x5 = sin−1x − sin−14x5 and take the sine of both sides:
    3x5 = x·√1 − 16x225 − 4x5·√1 − x2
  2. Multiply through by 5: 3x = x√25 − 16x2 − 4x√1 − x2.
  3. So x = 0, or 3 = √25 − 16x2 − 4√1 − x2.
  4. Rearrange and square: 25 − 16x2 = 9 + 24√1 − x2 + 16(1 − x2), which simplifies to 0 = 24√1 − x2, so x = ±1.
  5. Domain check: all three inverse sines need |x| ≤ 1, and x = 0, ±1 all satisfy the original equation (at x = 1, sin−10.8 + sin−10.6 = π2 = sin−11).

Answer x = 0, 1, −1.

P194 marksStandard ISC type
Solve: 2 tan−1(cos x) = tan−1(2 cosec x).
  1. Use 2 tan−1t = tan−12t1 − t2 on the left.
  2. With t = cos x: tan−12 cos x1 − cos2 x = tan−12sin x.
  3. Since 1 − cos2x = sin2x, the left argument is 2 cos xsin2 x.
  4. Equate arguments: 2 cos xsin2 x = 2sin x, so 2 cos x sin x = 2 sin2x, giving sin x (cos x − sin x) = 0.
  5. sin x = 0 is rejected (cosec x would be undefined), so tan x = 1.

Answer x = π4 (taking the principal solution).

Type 5 · Proving an identity

How to attack itConvert each inverse function to the same one (usually tan⁻¹), then apply the addition formula, checking the xy < 1 condition. Right-to-left is often easier than left-to-right.
P204 marksStandard ISC type
Prove that tan−112 + tan−115 + tan−118 = π4.
  1. Combine the first two. With x = 12, y = 15 we have xy = 110 < 1, so tan−1x + tan−1y = tan−1x + y1 − xy.
    = tan−112 + 151 − 110 = tan−1710910 = tan−179
  2. Now add the third term: x = 79, y = 18, xy = 772 < 1, so the sum is
    tan−179 + 181 − 772 = tan−165726572 = tan−11 = π4

Note Checking xy < 1 at each step is what makes this a proof rather than a manipulation — the formula has a different form when xy > 1.

P214 marksStandard ISC type
Prove that sin−135 − sin−1817 = cos−18485.
  1. Let A = sin−135, so sin A = 35 and cos A = 45 (A is in the first quadrant).
  2. Let B = sin−1817, so sin B = 817 and cos B = 1517.
  3. Then cos(A − B) = cos A cos B + sin A sin B = 45·1517 + 35·817 = 6085 + 2485 = 8485.
  4. Since sin A > sin B with both angles acute, A − B ∈ [0, π/2], which is inside the range of cos−1. Hence A − B = cos−18485.

Matrices

Types of matrices; transpose; symmetric and skew symmetric; operations; non-commutativity; invertible matrices (order up to 3).

Type 1 · Symmetric and skew symmetric matrices

How to attack itEverything here comes from one move: take the transpose of the whole expression and use (AB)′ = B′A′, (A + B)′ = A′ + B′. Then compare with the original.
P221 markNCERT Exemplar Ch 3, Example 12 · Heritage FT Q1(i)
If A and B are symmetric matrices of the same order, then (AB′ − BA′) is: (a) skew symmetric  (b) null  (c) symmetric  (d) none of these.
  1. A and B symmetric means A′ = A and B′ = B, so AB′ − BA′ = AB − BA.
  2. Take the transpose: (AB − BA)′ = (AB)′ − (BA)′ = B′A′ − A′B′ = BA − AB.
  3. That is −(AB − BA), so the matrix equals the negative of its own transpose.

Answer (a) skew symmetric.

Note It is not the null matrix: AB − BA vanishes only when A and B commute, which symmetry alone does not force.

P232 marksStandard ISC type
Express A = 3−152 as the sum of a symmetric and a skew symmetric matrix.
  1. Always use A = 12(A + A′) + 12(A − A′); the first bracket is symmetric, the second skew symmetric.
  2. A′ = 35−12, so A + A′ = 6444 and A − A′ = 0−660.

Answer A = 3222 + 0−330.

Note Check: the skew part must have zeros all down the diagonal. If it does not, you have made an arithmetic slip.

P242 marksExemplar-style
If a matrix A is both symmetric and skew symmetric, show that A is the zero matrix.
  1. Symmetric gives A′ = A; skew symmetric gives A′ = −A.
  2. So A = −A, hence 2A = O and A = O.

Type 2 · Matrix algebra: powers, polynomial identities, induction

How to attack itFor A2 = kA + mI, compute A2 once and compare entries. For a power An, compute A2 and A3, guess the pattern, then prove it by induction.
P252 marksStandard ISC type
If A = 3−24−2, find k such that A2 = kA − 2I.
  1. A2 = 3−24−2·3−24−2 = 1−24−4.
  2. kA − 2I = 3k − 2−2k4k−2k − 2.
  3. Comparing the (1,2) entries: −2k = −2, so k = 1. Every other entry then agrees.

Answer k = 1.

P264 marksStandard ISC type
If A = 1101, prove by induction that An = 1n01 for all n ≥ 1.
  1. Base case. For n = 1 the claim reads A = 1101, which is true.
  2. Inductive step. Assume Ak = 1k01. Then
    Ak+1 = Ak·A = 1k01·1101 = 1k + 101
  3. which is the claim for n = k + 1. By induction it holds for all n ≥ 1.
P272 marksExemplar-style
Give two non-zero 2 × 2 matrices A and B with AB = O.

Answer A = 1000, B = 0001 give AB = 0000, although neither factor is zero.

Note So the cancellation law fails for matrices: AB = O does not imply A = O or B = O. This is exactly what the syllabus means by ‘existence of non-zero matrices whose product is the zero matrix’.

P282 marksStandard ISC type
Show that (A + B)2 = A2 + 2AB + B2 holds only if AB = BA.
  1. (A + B)2 = (A + B)(A + B) = A2 + AB + BA + B2.
  2. This equals A2 + 2AB + B2 exactly when AB + BA = 2AB, i.e. BA = AB.

Trap Ordinary algebraic identities transfer to matrices only when the matrices concerned commute. Never expand a matrix square automatically.

Type 3 · Solving matrix equations for unknown entries

How to attack itEquate corresponding entries and solve the resulting simultaneous equations. Check every entry — an inconsistent system means no such matrix exists.
P292 marksStandard ISC type
Find x and y if 2x57y − 3 + 3−412 = 761514.
  1. The left side is 2x + 36152y − 4.
  2. Comparing (1,1): 2x + 3 = 7, so x = 2.
  3. Comparing (2,2): 2y − 4 = 14, so y = 9.
  4. The (1,2) and (2,1) entries already match, so the solution is consistent.

Answer x = 2, y = 9.

P302 marksStandard ISC type
If A = x00−1 satisfies A2 = I, find the possible values of x.
  1. A2 = x2001.
  2. Setting this equal to I gives x2 = 1.

Answer x = ±1.

Determinants

Determinants up to 3 × 3; properties; minors and cofactors; area of a triangle and collinearity; adjoint and inverse; consistency and solution of linear systems by matrices (Martin's rule).

Type 1 · Evaluating a determinant using properties

How to attack itLook for a row or column operation that creates a row/column of zeros, or that makes two rows/columns proportional (determinant then 0). Never expand a 3 × 3 determinant with messy entries before trying this.
P312 marksHeritage First Term 2024–25, Q6
Using properties of determinants, evaluate (ax + a−x)2(ax − a−x)21(ay + a−y)2(ay − a−y)21(az + a−z)2(az − a−z)21.
  1. For any t, (at + a−t)2 − (at − a−t)2 = 4, because the cross terms are +2 and −2 times at·a−t = 1.
  2. So C₁ − C₂ = 4 for every row, i.e. C₁ − C₂ = 4 C₃.
  3. Apply C₁ → C₁ − C₂ − 4C₃. Every entry of the new first column is 0.
  4. A determinant with a zero column is 0.

Answer 0.

Note Verified symbolically: the determinant is identically zero for all a, x, y, z.

P321 markHeritage First Term 2024–25, Q1(iv)
If a2bcc2 + aca2 + abb2caabb2 + bcc2 = k a2b2c2, then k = ?
  1. Take a common factor out of each column. C₁ = (a2, a2 + ab, ab) = a(a, a + b, b); C₂ = (bc, b2, b2 + bc) = b(c, b, b + c); C₃ = (c2 + ac, ca, c2) = c(c + a, a, c). So the determinant is
    abc acc + aa + bbabb + cc
  2. Apply C₃ → C₃ − C₁ − C₂. Row 1 gives (c + a) − a − c = 0; rows 2 and 3 both give −2b:
    abc ac0a + bb−2bbb + c−2b
  3. Apply R₂ → R₂ − R₃, which clears the third column except for one entry:
    abc ac0a−c0bb + c−2b
  4. Expand along C₃. The only non-zero entry is −2b at position (3,3), whose cofactor sign is +:
    abc · (−2b) aca−c = abc(−2b)(−ac − ac) = abc · 4abc

Answer The determinant is 4a2b2c2, so k = 4.

Note Every step above was checked symbolically. Pulling a common factor out of each column first is what makes this tractable — expanding the original 3 × 3 directly takes far longer than a 1-mark question deserves.

P334 marksStandard ISC type
Prove that 1aa21bb21cc2 = (a − b)(b − c)(c − a).
  1. Apply R₁ → R₁ − R₂ and R₂ → R₂ − R₃:
    0a − ba2 − b20b − cb2 − c21cc2
  2. Take (a − b) out of R₁ and (b − c) out of R₂, using a2 − b2 = (a − b)(a + b):
    (a − b)(b − c) 01a + b01b + c1cc2
  3. Expand along C₁: the only non-zero entry is the 1 in position (3,1), with cofactor +[(1)(b + c) − (1)(a + b)] = c − a.

Answer (a − b)(b − c)(c − a).

Type 2 · Determinant of a power, product or adjoint

How to attack itLearn the four rules and the questions become one-liners: |AB| = |A||B|, |An| = |A|n, |kA| = kn|A| for order n, and |adj A| = |A|n−1.
P342 marksHeritage First Term 2024–25, Q4
If A = x22x and |A4| = 625, find the value(s) of x.
  1. |A| = x2 − 4.
  2. |A4| = |A|4 = (x2 − 4)4.
  3. So (x2 − 4)4 = 625 = 54, giving x2 − 4 = ±5.
  4. x2 − 4 = 5 gives x2 = 9, so x = ±3. x2 − 4 = −5 gives x2 = −1, rejected over the reals.

Type 4 · Integration by parts

How to attack itChoose u by ILATE: Inverse, Log, Algebraic, Trigonometric, Exponential — whichever comes first is u. For ∫ex sin x dx, apply parts twice and solve for the integral.
P724 marksStandard ISC type
Evaluate ∫ex sin x dx.
  1. Let I = ∫ex sin x. Taking u = sin x, dv = ex dx: I = ex sin x − ∫ex cos x.
  2. Apply parts again to the second integral: ∫ex cos x = ex cos x + ∫ex sin x = ex cos x + I.
  3. So I = ex sin x − ex cos x − I, giving 2I = ex(sin x − cos x).

Answer ex2(sin x − cos x) + C.

Note Verified symbolically.

P732 marksStandard ISC type

Type 5 · Definite integrals by properties

How to attack itFour properties do almost all the work: ∫0af(x)dx = ∫0af(a−x)dx; odd/even over [−a, a]; the [0, 2a] rule; and splitting at the point where a modulus changes sign.
P744 marksStandard ISC type

Area bounded by simple curves, lines and the coordinate axes; area enclosed between two curves. Simple curves: lines, circles, parabolas, ellipses, polynomials, modulus and exponential functions.

Type 1 · Area under a curve and the axes

How to attack itSketch first, always. Decide whether to integrate in x or in y — integrating in y is often far shorter for a sideways parabola. Where the curve dips below the axis, integrate |y|.
P782 marksStandard ISC type
Find the area bounded by y = x2, the x-axis and the lines x = 1, x = 2.
  1. The curve is above the axis on [1, 2], so the area is ∫21x2.
  2. = [x33]12 = 83 − 13.

P794 marksStandard ISC type
Find the area of the region bounded by y = |x + 1|, the x-axis, x = −3 and x = 0.
  1. y = |x + 1| is V-shaped with its vertex at (−1, 0). Split at x = −1.
  2. On [−3, −1], |x + 1| = −(x + 1); on [−1, 0], |x + 1| = x + 1.
    ∫−1−3−(x + 1) + ∫0−1(x + 1) = 2 + 12

P804 marksStandard ISC type
Find the area enclosed by the ellipse x29 + y24 = 1.

  2. In the first quadrant y = 2√1 − x29, so the area is 4·∫302√1 − x29.

Type 2 · Area between two curves

How to attack itFind the intersections first — they are the limits. Then integrate (upper − lower) in x, or (right − left) in y. Choosing the y-direction avoids splitting the region in most parabola-and-line problems.
P814 marksStandard ISC type
Find the area of the region bounded by y2 = 4x and the line y = 2x − 4.
  1. Intersections: substitute x = 12(y + 4) into y2 = 4x, giving y2 = 2(y + 4), i.e. y2 − 2y − 8 = 0, so y = 4 or y = −2.
  2. Integrate in y: the line gives x = y + 42 and the parabola x = y24. For −2 ≤ y ≤ 4 the line is to the right.
    Area = ∫4−2[y + 42 − y24] dy
  3. = [y24 + 2y − y312]−24 = (4 + 8 − 163) − (1 − 4 + 23) = 203 − (−73).

Note Verified symbolically. Integrating in x would need the region split at x = 1 — three times the work.

P824 marksStandard ISC type

Linear Programming

Terminology; mathematical formulation; graphical solution in two variables; feasible and infeasible regions (bounded and unbounded); optimal feasible solutions, up to three non-trivial constraints.

Type 1 · Objective questions on regions and corner points

How to attack itFor an inequality, test the origin: if it satisfies the inequality the region is the half plane containing the origin. Strict inequality ⇒ open half plane (boundary excluded).
P851 markHeritage First Term 2024–25, Q19(ii)
The solution set of the inequation 3x + 5y < 4 is: (a) an open half plane not containing the origin; (b) the whole xy-plane except the points on 3x + 5y = 4; (c) an open half plane containing the origin; (d) none of these.
  1. Test the origin: 3(0) + 5(0) = 0 < 4  ✓ So the origin satisfies the inequality and lies in the solution set.
  2. The inequality is strict, so the boundary line 3x + 5y = 4 is excluded — the region is open.

Answer (c) an open half plane containing the origin.

Note ‘Open’ means boundary excluded (< or >); ‘closed’ means boundary included (≤ or ≥).

P861 markNCERT Exemplar Ch 12, Q34 · Heritage FT Q19(v)
The corner points of the feasible region are (0, 3), (1, 1) and (3, 0). Let Z = px + qy with p, q > 0. Find the condition on p and q so that the minimum of Z occurs at both (3, 0) and (1, 1).
  1. Z(3, 0) = 3p, Z(1, 1) = p + q, Z(0, 3) = 3q.
  2. The minimum is attained at both (3, 0) and (1, 1), so these values are equal: 3p = p + q, giving q = 2p, i.e. p = q2.
  3. Check it really is the minimum: then Z(0,3) = 3q = 6p, which exceeds 3p.  ✓

Answer p = q2 (equivalently q = 2p).

Note When two corner points give the same optimal value, every point on the segment joining them is also optimal — the problem has infinitely many optimal solutions.

P872 marksHeritage First Term 2024–25, Q20
Find the number of feasible solutions of the LPP: maximise Z = 15x + 30y subject to 3x + y ≤ 12, x + 2y ≤ 10, x ≥ 0, y ≥ 0.
  1. The constraints define a bounded region in the first quadrant with corner points (0, 0), (4, 0), (0, 5) and the intersection of 3x + y = 12 with x + 2y = 10.
  2. Solving those two: from the first y = 12 − 3x, so x + 24 − 6x = 10, giving x = 145 and y = 185.
  3. A feasible solution is any point of the feasible region, not just a corner. The region is a two-dimensional polygon.

Answer Infinitely many feasible solutions.

Trap Do not answer ‘4’. There are four corner points, but infinitely many feasible solutions. Read which of the two is being asked for.

Type 2 · Formulating and solving a word problem graphically

How to attack itFour lines, always: (1) define the variables with units; (2) write the objective; (3) write the constraints including x, y ≥ 0; (4) tabulate Z at every corner point and pick the best. State the answer in the words of the problem.
P884 marksHeritage First Term 2024–25, Q22
Every gram of rice provides 0·1 g of protein and 0·25 g of carbohydrates; for wheat the values are 0·05 g and 0·5 g. Rice costs ₹40 per kg and wheat ₹60 per kg. The minimum daily requirement for a child is 50 g of protein and 200 g of carbohydrates. In what quantities should rice and wheat be mixed to meet the requirement at least cost? Formulate and solve graphically.
  1. Let the daily diet contain x kg of rice and y kg of wheat (so 1000x g and 1000y g).
  2. Protein: 0·1(1000x) + 0·05(1000y) = 100x + 50y ≥ 50.
  3. Carbohydrates: 0·25(1000x) + 0·5(1000y) = 250x + 500y ≥ 200.
  4. Dividing through: 2x + y ≥ 1 and x + 2y ≥ 0·8, with x, y ≥ 0. Minimise Z = 40x + 60y.
  5. The region is unbounded above. Its corner points are (0, 1), (0·4, 0·2) and (0·8, 0):
    Corner pointZ = 40x + 60y
    (0, 1)₹60
    (0·4, 0·2)₹28
    (0·8, 0)₹32
  6. Because the region is unbounded we must confirm the minimum: the open half plane 40x + 60y < 28 has no point in common with the feasible region, so ₹28 is genuinely the minimum.

Answer 400 g of rice and 200 g of wheat daily, at a minimum cost of ₹28.

Note Verified: the three corner values are 60, 28 and 32. The unboundedness check is worth a mark and is nearly always omitted.

P896 marksStandard ISC type
A manufacturer makes two products A and B. Each unit of A needs 2 hours on machine I and 1 hour on machine II; each unit of B needs 1 hour on I and 2 hours on II. Machine I is available for 10 hours and machine II for 8 hours a day. Profits are ₹30 per unit of A and ₹20 per unit of B. Find the daily production plan maximising profit.
  1. Let x units of A and y units of B be made daily.
  2. Machine I: 2x + y ≤ 10. Machine II: x + 2y ≤ 8. x, y ≥ 0.
  3. Maximise Z = 30x + 20y.
  4. Corner points: (0, 0), (5, 0), (0, 4) and the intersection of 2x + y = 10, x + 2y = 8. Solving: y = 10 − 2x, so x + 20 − 4x = 8, x = 4, y = 2.
    Corner pointZ = 30x + 20y
    (0, 0)0
    (5, 0)₹150
    (4, 2)₹160

P902 marksExemplar-style
The feasible region of an LPP is unbounded and Z = 3x + 4y is to be maximised. What can you conclude?
  1. For an unbounded region a maximum need not exist. Let M be the largest value of Z at a corner point.
  2. M is the maximum only if the open half plane 3x + 4y > M has no point in common with the feasible region.
  3. If that half plane does meet the region, Z can be made arbitrarily large and there is no maximum.

Answer Z may have no maximum; the corner-point value must be tested against the open half plane 3x + 4y > M.

Trap With an unbounded region, quoting the largest corner value without that test is incomplete. With a bounded region the corner point method always works.
