1Relations and FunctionsQ1(i)[1]
The relation R = {(a, a), (b, b), (c, c)} on the set {a, b, c} is best described as:

Test all three properties, then name the strongest

  1. Reflexive? The set has three elements and all three of (a, a), (b, b), (c, c) are in R. Yes.
  2. Symmetric? Every pair in R has both coordinates equal, so whenever (x, y) ∈ R the pair (y, x) is the same pair. Yes — vacuously, but yes.
  3. Transitive? (x, y) and (y, z) in R force x = y = z, and (x, z) is then in R. Yes.
  4. All three hold, so R is an equivalence relation — in fact it is the identity relation on the set.

Note The paper offers “reflexive”, “symmetric” and “transitive” alongside “equivalence relation”, and strictly all four are true statements about R. The intended answer is the one that says all of them at once; the options here have been sharpened so that only one can be right.

Answer an equivalence relation

2Relations and FunctionsQ1(ii)[1]
Consider f : ℝ → ℝ given by f(x) = x − 2. Then f is:

Straight-line functions on all of ℝ

  1. One-to-one. f(x₁) = f(x₂) means x₁ − 2 = x₂ − 2, so x₁ = x₂.
  2. Onto. Given any y ∈ ℝ, take x = y + 2; then f(x) = y. Every real number is hit.
  3. Both, so f is bijective.

Note Any f(x) = ax + b with a ≠ 0 is a bijection of ℝ onto ℝ. It is only when the domain or codomain is cut down — to ℕ, say, or to ℝ − {0} — that one of the two properties can fail.

Answer bijective

4MatricesQ1(iv)[1]
If A and B are square matrices of the same order, then (A + B)(A − B) equals:

Expand without assuming AB = BA

  1. Expand keeping the order of every product, because matrix multiplication is not commutative:
    (A + B)(A − B) = A·A − A·B + B·A − B·B
  2. That is A2 − AB + BA − B2, which is the same thing as A2 − B2 + BA − AB.
  3. It collapses to A2 − B2 only in the special case AB = BA.

Trap −AB + BA is not zero and not −2AB. Keep the two middle terms separate and in the order the expansion produced them.

Answer A2 − B2 + BA − AB

8Continuity and DifferentiabilityQ1(viii)[1]
If f(x) = {x + 2,if x < 0−x2 − 2,if 0 ≤ x < 1x,if x ≥ 1 then the number of point(s) of discontinuity of f is/are:

One test per join

  1. There are two joins to examine, x = 0 and x = 1.

10Applications of DerivativesQ1(x)[1]
f(x) = xx has a critical point at:

Logarithmic differentiation

  1. Take logarithms, since the variable is in both the base and the index:
    log f = x log x  ⇒  f′f = log x + 1
  2. So f′(x) = xx(1 + log x). For x > 0, xx is never zero, so
    f′(x) = 0  ⇔  log x = −1  ⇔  x = e−1

Note xx is only defined for x > 0 here, so x = 0 is not in the domain and cannot be a critical point. The value there, (1/e)1/e ≈ 0·692, is the function's minimum.

Answer x = e−1

11Applications of DerivativesQ1(xi)[1]
A curve is y = 7x − x3 and x increases at the rate of 2 units per second. The rate at which the slope of the curve is changing when x = 5 is:

Differentiate the slope, not the curve

  1. The slope itself is the thing being differentiated, so write it down first:
    m = dydx = 7 − 3x2
  2. Now differentiate m with respect to time, using the chain rule:
    dmdt = −6x·dxdt
  3. With x = 5 and dxdt = 2:
    dmdt = −6(5)(2) = −60 units/sec

Trap “The rate at which the slope is changing” is dm/dt, not dy/dt. Differentiating y instead gives (7 − 3·25)(2) = −136, which answers a question nobody asked.

12IntegralsQ1(xii)[1]
A teacher writes ∫f(a) da = −cos(a2 + 1) + C on the board and asks which function she integrated. Sameer says ‘sin(a2 + 1)’, Danish says ‘−sin(a2 + 1)’, Meera says ‘2a sin(a2 + 1)’ and Deepa says ‘−2a sin(a2 + 1)’. Who is correct?

Differentiate the stated answer

  1. Integration is undone by differentiation, so simply differentiate what she wrote:
    f(a) = dda[ −cos(a2 + 1) ] = sin(a2 + 1) · dda(a2 + 1)
  2. The inner derivative is 2a, so
    f(a) = 2a sin(a2 + 1)
  3. That is Meera's answer.

Trap Forgetting the chain-rule factor 2a gives Sameer's answer, which is the single commonest slip in the whole chapter. Check any integral by differentiating it back.

Answer Meera

13IntegralsQ1(xiii)[1]
∫baf(x) dx is equal to:

The reflection property

  1. Substitute x = a + b − t, so dx = −dt. The limits turn over: x = a gives t = b and x = b gives t = a.
    ∫baf(x) dx = −∫abf(a + b − t) dt = ∫baf(a + b − t) dt
  2. The name of the variable of integration does not matter, so this is ∫baf(a + b − x) dx.

Note The special case b = a, lower limit 0, is the familiar ∫a0f(x) dx = ∫a0f(a − x) dx. The general form is what is needed whenever the lower limit is not 0.

Answer ∫baf(a + b − x) dx

15Linear ProgrammingQ1(xv)[1]
A set of values of the decision variables that satisfies the linear constraints and the non-negativity conditions of an L.P.P. is called its:

Vocabulary of linear programming

  1. A point that obeys every constraint and is non-negative in each variable is a feasible solution. The set of all of them is the feasible region.
  2. A corner point is a vertex of that region, not any old point of it; an infeasible solution breaks at least one constraint; and unbounded describes a region that extends indefinitely, not a single point.

Note The paper's own option list says “feasible region”. The region is the set of all such points, so for a single set of values the precise word is solution — that is what is used here.

Answer feasible solution

16Relations and FunctionsQ1(xvi)[1]
Assertion (A): f : ℝ − {0} → ℝ − {0} defined by f(x) = 1x is one-one and onto.
Reason (R): f : ℕ → ℝ − {0} defined by f(x) = 1x is one-one and onto.
Which one is correct?

Onto-ness depends on the domain

  1. The Assertion. On ℝ − {0}, 1x₁ = 1x₂ forces x₁ = x₂, so f is one-one; and any non-zero y is f(1/y). So it is one-one and onto — true.
  2. The Reason. On ℕ the same formula is still one-one, but its range is only {1, 12, 13, …}. The number 2 lies in ℝ − {0} and has no preimage in ℕ, so it is not onto — false.
  3. So the Assertion is true and the Reason is false.

Trap Both statements print the same formula, which invites you to give them the same verdict. Onto-ness depends on the domain and codomain, never on the formula alone.

Answer Assertion is true but Reason is false

From the paper: Q1(xvi), Section A

17MatricesQ1(xvii)[1]
Assertion (A): the matrices A = −32−54 and B = 4−25−3 are such that A100B = BA100.
Reason (R): AB = BA implies AnB = BAn for all positive integers n.
Which one is correct?

Verify AB = BA, then induct

  1. Test the Reason's hypothesis first — multiply the two matrices both ways:
    AB = −200−2   and   BA = −200−2
  2. So AB = BA (both equal −2I).
  3. The Reason. If AB = BA then A2B = A(AB) = A(BA) = (AB)A = (BA)A = BA2, and the same step repeated gives AnB = BAn for every n. True.
  4. The Assertion is the case n = 100 of exactly that, so it is true and the Reason is why. Both true, Reason the correct explanation.

Note Do not take AB = BA on trust because the question hints at it — here it happens to hold, and checking costs two lines. If it had failed, the Reason would still be true and the Assertion false.

Answer Both are true and Reason is the correct explanation of Assertion

25Relations and FunctionsQ6(i)[1]
L is the set of all rail lines on a railway track and R is the relation on L defined by R = {(l₁, l₂) : l₁ is parallel to l₂}. Then R is:

Same direction, passed along a chain

  1. Take any three rail lines with (l₁, l₂) ∈ R and (l₂, l₃) ∈ R, that is l₁ ∥ l₂ and l₂ ∥ l₃.
  2. Parallel lines have the same direction, so l₁ and l₃ share l₂'s direction and are therefore parallel to each other: (l₁, l₃) ∈ R.
  3. So R is transitive. (It is in fact an equivalence relation on L, since every line is parallel to itself and parallelism is symmetric.)

Note Parallelism counts a line as parallel to itself in this convention — that is what makes R reflexive and lets the equivalence classes be ‘all lines of a given direction’.

Answer transitive

27Relations and FunctionsQ6 OR (i)[1]
A = {D, S, C, K} are four chocolates costing ₹5, ₹10, ₹20 and ₹50 a piece respectively, and R = {(x, y) : cost of x ≤ cost of y} is a relation on A. The number of ordered pairs in R is:

Order by cost, then count downward

  1. Order the four by cost: D (5) < S (10) < C (20) < K (50). All four costs are different, so “cost of x ≤ cost of y” means x is at or before y in that order.
  2. Counting the pairs from each first element:
    • D relates to D, S, C, K — 4 pairs
    • S relates to S, C, K — 3 pairs
    • C relates to C, K — 2 pairs
    • K relates to K — 1 pair
  3. Total 4 + 3 + 2 + 1 = 10. In roster form
    R = {(D,D), (D,S), (D,C), (D,K), (S,S), (S,C), (S,K), (C,C), (C,K), (K,K)}

Note For n items with all costs distinct, a ‘≤’ relation always has n(n+1)/2 pairs — here 4·5/2 = 10. Six would be the count for a strict ‘<’.

Answer 10

28Relations and FunctionsQ6 OR (ii)[1]
For the same relation R = {(x, y) : cost of x ≤ cost of y} on the four chocolates, R is:

Transitivity is inherited from ≤ on numbers

  1. Suppose (x, y) ∈ R and (y, z) ∈ R, i.e. cost(x) ≤ cost(y) and cost(y) ≤ cost(z).
  2. The ordinary order on numbers is transitive, so cost(x) ≤ cost(z), which is precisely (x, z) ∈ R.
  3. So R is transitive, and the argument used nothing about the particular numbers 5, 10, 20, 50 — equal costs would do no harm, since ≤ allows equality.

Trap Failing to be symmetric has no bearing on transitivity. R here is reflexive and transitive but not symmetric — (D, K) is in R and (K, D) is not — and that is perfectly consistent.

Answer transitive, because ≤ is transitive on the costs

29Continuity and DifferentiabilityQ7[1]
If x = a cos θ and y = b sin θ, then d2ydx2 equals:

Parametric second derivative: divide by dx/dθ twice

  1. Differentiate each parametrically and divide:
    dxdθ = −a sin θ,    dydθ = b cos θ  ⇒  dydx = −ba cot θ
  2. For the second derivative, differentiate that with respect to θ and divide by dx/dθ again — not with respect to x:
    d2ydx2 = ddθ( −ba cot θ )dxdθ = ba cosec2θ−a sin θ = −ba2 cosec3θ
  3. Finally turn θ back into y. Since y = b sin θ, sin θ = yb and cosec3θ = b3y3:
    d2ydx2 = −ba2·b3y3 = −b4a2y3

Trap The commonest loss of marks here is dividing by dx/dθ only once. The second derivative needs it a second time, and forgetting that leaves an answer one power of a too large.

Answer −b4a2y3

30Applications of DerivativesQ7 OR[1]

(dA₂/dx) ÷ (dA₁/dx)

Parts with the inverse function as u, then divide out

  1. Integrate by parts with u = tan−1x (the inverse function is always the part to differentiate) and dv = x2dx:
    I = x33 tan−1x − 13 ∫x31 + x2 dx
  2. The remaining integrand is top-heavy, so divide before integrating:
    x31 + x2 = x − x1 + x2
    ∫x31 + x2 dx = x22 − 12 log(1 + x2)
  3. Putting it back, with the 13 outside:
    I = x33 tan−1x − x26 + 16 log(1 + x2) + C

Note Differentiating the answer back is worth the thirty seconds: the two middle terms must recombine into 13·x31 + x2.

Trap The minus sign from parts applies to the whole remaining integral, so it flips both of the terms that come out of it — hence −x26 but +16 log(1 + x2).

Evaluate ∫82√10 − x√x + √10 − x dx:

Reflection property: a + b = 10

  1. Nothing here can be integrated directly. Use the reflection property, with a = 2 and b = 8, so a + b = 10 — the very number inside the radical:
    I = ∫82√10 − x√x + √10 − x dx = ∫82√x√10 − x + √x dx
  2. Add the two expressions for I. The denominators are identical and the numerators add to it, so everything cancels:
    2I = ∫821 dx = 8 − 2 = 6
  3. Hence I = 3.

Note Whenever the limits add to the number buried inside the integrand, that is the signal for this property. The answer is always half the length of the interval, whatever function sits on top.

Answer 3
